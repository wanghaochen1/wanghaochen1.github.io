文章简介

Introduction

本问提出一种自适应量化事件触发四旋翼飞行器姿态控制方法，并通过指定时间预设性能对无人机的姿态进行控制约束。此外，使用RBFNN解决了系统的不确定性；联合干扰观测器喝RBFNN对外界符合扰动干扰进行最优误差逼近。理论证明系统信号UUB，且没有芝诺效应；实验验证了控制策略的优越性。
